# Pyantasy `.github`

> Org profile README and shared engineering process for every Pyantasy repository.

## Why this exists

Agents and humans need one place to find the **PR-required** merge rule that applies across Shake, Seen, sports games, and other products — without relying on paid GitHub branch protection ([PYA-73](/PYA/issues/PYA-73) cancelled; process documented in [PYA-74](/PYA/issues/PYA-74)).

## What’s here

| Path | Purpose |
|------|---------|
| [`profile/README.md`](profile/README.md) | Organization profile (visible on the [Pyantasy](https://github.com/Pyantasy) org page) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Reusable contributing guide (org default community health file) |
| [`docs/pr-required-process.md`](docs/pr-required-process.md) | Full PR-required process, limits, and PYA-73 background |

## Quick start (contributors)

1. Read [CONTRIBUTING.md](CONTRIBUTING.md).
2. Never treat direct pushes to `main` / `master` as normal practice.
3. Open a PR; get at least one review before merge.

## Changing these docs

Follow the same process this repo describes: feature branch → PR → review → merge.
